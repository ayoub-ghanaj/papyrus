# Papyrus image assets

Generated with the built-in image generation tool for the login carousel. The original outputs were copied into `src/main/resources/papyrus/carousel/` without alteration. These are newly generated scenes, not photographs of identifiable real libraries.

## library.png

Use case: photorealistic-natural. Asset type: login carousel image for Papyrus, a desktop library manager. Create a refined editorial photograph of an inviting contemporary library with pale oak shelves, cream walls, dark forest green seating and warm late-afternoon sunlight. Quiet elegant reading space, no people. Vertical 4:5 composition, beautiful realistic materials, visually calm with the focal point near the center. No text, no logos, no watermark. This is one of three coordinated images; warm cream, sage and deep emerald palette.

## desk.png

Use case: photorealistic-natural. Asset type: login carousel image for Papyrus, a desktop library manager. Create a refined editorial still life of an open book and a small stack of beautifully bound unbranded green and sand-colored books on a pale oak library desk, gentle window shadows, blurred shelves in the background. Vertical 4:5 composition with centered tactile details, realistic paper edges and soft afternoon light. No readable text, no logos, no watermark, no people. Coordinated warm cream, sage and deep emerald palette.

## alcove.png

Use case: photorealistic-natural. Asset type: login carousel image for Papyrus, a desktop library manager. Create a refined editorial photograph of a serene Moroccan-inspired library reading alcove with a simple graceful arch, pale plaster, restrained oak bookshelves, emerald green upholstered chair, filtered warm sunlight, a subtle indoor plant. Contemporary and understated, realistic architectural photography, no ornate visual clutter. Vertical 4:5 composition, focal point centered. No people, no text, no logos, no watermark. Coordinated warm cream, sage and deep emerald palette.

## Vector artwork

The editable SVG logo and mark in `assets/brand/` and the matching icon set in `assets/icons/` were drawn for Papyrus. The mark combines an open book and a papyrus leaf. Native application icons are exported to `packaging/papyrus.png`, `packaging/papyrus.ico`, and the embedded `papyrus/icon.png` resource.
